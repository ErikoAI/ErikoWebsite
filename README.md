# Eriko website

Static site, no build step. Serve this folder with any static host or open `index.html`.

- `index.html`: page, styles and script (Home, About and Contact views switch in-page).
- `assets/`: logos, founder portrait and Eriko mascot avatars used in the product screens.

The contact form submits to Netlify Forms (form name `contact`), so it only delivers when the site is hosted on Netlify. Set the notification email under Project configuration > Notifications > Emails and webhooks > Form submission notifications.
